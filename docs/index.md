# dynibo

Dynibo is a fast, lightweight, and reliable library for runtime-sized robot
kinematics and dynamics. Its Rust core is available through Rust, Python, C,
and C++ interfaces.

Choose the API documentation for your language:

- [Python API](python.md)
- [C API](c-api/dynibo_8h.md)
- [Rust API](https://docs.rs/dynibo)

For source code, installation details, and complete examples, visit the
[dynibo repository](https://github.com/xiaojie-xue/dynibo).
