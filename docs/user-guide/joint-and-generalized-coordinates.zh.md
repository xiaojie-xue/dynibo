# 关节与广义坐标

Dynibo 区分关节状态输入和广义输出，这一点对浮动基模型尤其重要。

## 尺寸

定义：

- `J = joint_count`：URDF 中非固定关节的数量。
- `G = generalized_count`：雅可比列数、质量矩阵维度和广义力向量长度。

固定基模型满足 `G = J`，浮动基模型满足 `G = J + 6`。

输入 `q`、`qd` 和 `qdd` 始终严格包含 `J` 个值，顺序与 URDF 中的非固定关节一致。
浮动基坐标不会放在这些数组开头；固定 `Robot` 保存根节点 frame，而 `FloatingRobot`
的每次计算都显式传入包含位姿、速度和加速度的 `BaseState`。

## 广义量排列顺序

固定基广义向量直接使用关节顺序。浮动基向量顺序为：

```text
[base angular xyz, base linear xyz, 非固定 URDF 关节...]
```

对于广义力，前六个值是世界坐标系下根节点的 wrench：

```text
[base torque xyz, base force xyz, 标量关节力...]
```

相同顺序也用于雅可比矩阵的列，以及质量矩阵的两个轴。

## Buffer 尺寸

| 数值 | 元素数量 |
|---|---:|
| `q`、`qd`、`qdd` | `J` |
| Pose | 平移 3 + 四元数 4 |
| Twist | 6 |
| 雅可比矩阵或其导数 | `6 * G` |
| 质量矩阵 | `G * G` |
| 广义力 | `G` |

C 和 Rust 的矩阵及广义力操作要求调用方提供输出 buffer。Python 和 C++ 会分配返回的
tuple 或 vector，但结果尺寸完全相同。

## 关节限制

URDF limit 属于模型。逆运动学在更新候选状态时应用支持的关节限制。其他计算会验证
数组长度和数值是否有限，但不会静默裁剪调用方提供的关节状态。
