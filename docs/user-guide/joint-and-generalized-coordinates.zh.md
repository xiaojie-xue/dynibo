# 关节与广义坐标

Dynibo 区分关节状态输入和广义输出，这一点对浮动基座模型尤其重要。

## 尺寸

定义：

- `J = joint_count`：URDF 中非固定关节的数量。
- `G = generalized_count`：雅可比列数、质量矩阵维度和广义力向量长度。

固定基座模型满足 `G = J`，浮动基座模型满足 `G = J + 6`。

输入 `q`、`qd` 和 `qdd` 始终严格包含 `J` 个值，按 Dynibo 从根 link 出发的**广度优先拓扑顺序**
排列非固定关节（同一父 link 下的子关节保持 URDF 中的声明顺序）。对于带分支的机器人，
该顺序可能与 URDF 文本出现顺序不同；在 Rust 中可通过 `joint_name(i)` 确认。
浮动基座坐标不会拼接在这些数组开头；固定基座 `Robot` 内部保存根节点位姿，而 `FloatingRobot`
的每次计算都显式传入包含位姿、速度和加速度的 `BaseState`。

## 广义量排列顺序

固定基座广义向量直接使用关节顺序。浮动基座向量顺序为：

```text
[base angular xyz, base linear xyz, 非固定 URDF 关节...]
```

对于广义力，前六个值是世界坐标系下根节点的 wrench：

```text
[base torque xyz, base force xyz, 标量关节力...]
```

相同顺序也用于雅可比矩阵的列，以及质量矩阵的行和列。

## 缓冲区尺寸

| 数值 | 元素数量 |
|---|---:|
| `q`、`qd`、`qdd` | `J` |
| Pose | 平移 3 + 四元数 4 |
| Twist | 6 |
| 雅可比矩阵或其导数 | `6 * G` |
| 质量矩阵 | `G * G` |
| 广义力 | `G` |

C 和 Rust 的矩阵及广义力操作要求调用方提供输出缓冲区。Python 返回 NumPy 数组或
写入 `out=`，C++ 返回 `std::vector` 或通过 `*_into` 写入预分配缓冲区，结果尺寸完全相同。

## 关节限制

URDF 关节限位属于模型属性。逆运动学在更新候选状态时会应用支持的关节限位；其他计算
只校验数组长度和数值是否为有限值，不会静默截断调用方传入的关节状态。
